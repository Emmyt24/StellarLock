# Issue #978 — Remove unused placeholder images from `public/`

**GitHub:** https://github.com/StellarLock/StellarLock/issues/978  
**Status:** Resolved in PR #1006  
**Area:** `public/` — static assets

---

## Problem

Five scaffold images that were generated by the Next.js project template were committed to
`public/` and shipped with every production build. None of them were referenced anywhere in
the application source:

| File | Size |
|---|---|
| `public/placeholder.jpg` | ~6 KB |
| `public/placeholder.svg` | ~1 KB |
| `public/placeholder-logo.png` | ~8 KB |
| `public/placeholder-logo.svg` | ~1 KB |
| `public/placeholder-user.jpg` | ~7 KB |

Because Vite copies everything in `public/` verbatim into the build output, these files
bloated every deployment artifact and were publicly reachable at their respective paths
(`/placeholder.jpg`, etc.) with no benefit to users.

---

## Investigation

A repo-wide search for each filename confirmed zero references across:

- All `src/**/*.{ts,tsx}` source files
- All `e2e/**/*.ts` Playwright specs
- All `*.md` documentation files
- `index.html` and other root-level config files

---

## Resolution

All five files were deleted. The deletion was verified by:

1. Confirming `pnpm build` completes without errors.
2. Confirming `pnpm test:e2e` passes — no spec attempted to load any placeholder asset.

---

## Impact

- Build output is smaller by ~23 KB.
- No placeholder paths are publicly accessible in production.
- No application functionality was affected.
